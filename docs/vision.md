# Vision: "Dark Software"

## North Star
Ghost Ops moves beyond maintenance. It treats source code as **ephemeral**—generated by AI intent, compiled to **WASM**, executed in a sandbox, and discarded when a better version is evolved.

## Core Principles
*   **Zero-Human Operations (ZHO):** No JIRA tickets. The system patches and optimizes itself.
*   **Just-In-Time Execution:** Services exist only when needed, reducing cold starts (<10ms) and carbon footprint.
*   **Simple-First Architecture:** Avoid complexity. If a feature serves only 1% of use cases, it is deferred.
*   **Ephemeral by Default:** Code is a liability. The less code we persist, the better.

## Roadmap Phases

### [PHASE-0: Hygiene & Foundations]
*Focus: Stabilization, Developer Experience, and CI/CD.*
- **Goal:** Ensure the codebase is clean, testable, and easy to run.
- **Key Deliverables:**
    - Comprehensive README and Makefile.
    - Automated Linting and Formatting.
    - structured Logging and Metrics foundations.
    - Basic Health Checks.

### [PHASE-1: MVP - The Self-Healing Loop]
*Focus: Closing the loop between Intent, Code, and Runtime.*
- **Goal:** A system that can take a high-level intent, generate code, run it, and fix it if it breaks.
- **Key Deliverables:**
    - Robust AI Evolution Engine (Intent -> WASM).
    - Shadow Mode & Blue/Green Deployments (Zero Downtime).
    - Persistent State Management (JSON/SQLite).
    - Basic CLI for interaction.

### [PHASE-2: Scale - Distributed & Resilient]
*Focus: Moving from a single binary to a distributed system.*
- **Goal:** Run thousands of ephemeral services across a cluster.
- **Key Deliverables:**
    - Distributed State Store (Etcd/Redis integration).
    - Remote WASM Registry (OCI compliant).
    - Horizontal Scaling & Leader Election.
    - Advanced Telemetry (Tracing, Alerting).

### [PHASE-3: Future - Autonomous Evolution]
*Focus: The system becomes self-aware and self-improving.*
- **Goal:** The system optimizes code based on runtime metrics without human intervention.
- **Key Deliverables:**
    - Feedback Loop: Runtime Metrics -> AI Re-Prompting.
    - Multi-Language Guest SDKs (Rust, Python).
    - Security: Automated Vulnerability Scanning & Patching.
    - "Dark Mode": Fully autonomous operation.
